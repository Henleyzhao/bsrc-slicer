# BSRC Slicer

专为 **BSRC BS3DP 400PRO** 定制的 3D 打印切片软件，基于 OrcaSlicer 开发。

## 下载安装

👉 点击右侧 [Releases](https://github.com/Henleyzhao/bsrc-slicer/releases) 下载最新版  
下载 `BSRC_Slicer_v1.0.0_Setup.exe`，双击安装即可。

## 内置配置

- 🖨 打印机：BSRC BS3DP 400PRO（0.2 / 0.4 / 0.6 / 0.8mm 喷嘴）
- 🧵 耗材：PLA / PETG / ABS / TPU
- ⚙️ 工艺：Standard（标准）/ Quality（精细）/ Draft（草稿）

## 打印机规格

| 参数 | 规格 |
|------|------|
| 打印体积 | 400 × 400 × 400 mm |
| 运动系统 | CoreXY |
| 最大速度 | 700 mm/s |
| 挤出方式 | Direct Drive |
| 固件 | Klipper |
| 自动调平 | 36 点 |
